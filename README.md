# College Wi‑Fi Auto Login

A minimal V1 project for a campus captive-portal login flow.

## Included in V1

- target SSID configuration
- credential save/load from a simple local file
- connectivity checks
- captive portal detection
- portal login attempt
- local logging

## Build

```bash
go build ./...
```

This project is intentionally lean and Linux-testable for local development.
